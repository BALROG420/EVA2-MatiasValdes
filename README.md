## Instalación

### 1. Crear entorno virtual:

```
python3 -m venv venv
```

### 2. Iniciar Entorno Virtual:
Linux/Mac:
```
source venv/bin/activate
```

Windows:
```
venv\Scripts\activate
```

### 3. Instalar dependencias:

```
pip install -r requirements.txt
```
